# Customer Support Ticket Classification

A Machine Learning project that classifies customer support tickets into relevant categories based on their text.

## Features

* Text preprocessing
* Ticket classification using Machine Learning
* Accuracy evaluation
* Dataset-based analysis

## Technologies

* Python
* Pandas
* Scikit-learn
* Machine Learning

## Dataset

`customer_support_tickets.csv`

## Run the Project

```bash
pip install pandas scikit-learn
python ticket_classification.py
```
